## 产品特点

**劳动节**

通常是年度与全球性的节日，目的是为了庆祝

[劳动阶级](https://zh.wikipedia.org/wiki/%E5%8B%9E%E5%8B%95%E9%9A%8E%E7%B4%9A)

对社会和经济所做的贡献。世界上大多数国家或地区的劳动节是在5月1日，因此通常也称之为

[国际劳动节](https://zh.wikipedia.org/wiki/%E5%9B%BD%E9%99%85%E5%8A%B3%E5%8A%A8%E8%8A%82)

，是纪念

[美国](https://zh.wikipedia.org/wiki/%E7%BE%8E%E5%9B%BD)

发生的

[干草市场屠杀](https://zh.wikipedia.org/wiki/%E5%B9%B2%E8%8D%89%E5%B8%82%E5%9C%BA%E5%B1%A0%E6%9D%80)

。

[美国](https://zh.wikipedia.org/wiki/%E7%BE%8E%E5%9B%BD)

和

[加拿大](https://zh.wikipedia.org/wiki/%E5%8A%A0%E6%8B%BF%E5%A4%A7)

的劳动节是在9月的第一个星期一。

[新西兰](https://zh.wikipedia.org/wiki/%E7%B4%90%E8%A5%BF%E8%98%AD)

的劳动节是十月的第4个星期一。

[澳大利亚](https://zh.wikipedia.org/wiki/%E6%BE%B3%E5%A4%A7%E5%88%A9%E4%BA%9A)

不同的地区对劳动节有不同的规定。而在

[日本](https://zh.wikipedia.org/wiki/%E6%97%A5%E6%9C%AC)

，类似的节日在

[11月23日](https://zh.wikipedia.org/wiki/11%E6%9C%8823%E6%97%A5)

，称为

[勤劳感谢之日](https://zh.wikipedia.org/wiki/%E5%8B%A4%E5%8B%9E%E6%84%9F%E8%AC%9D%E4%B9%8B%E6%97%A5)

。
